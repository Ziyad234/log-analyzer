# Python Log Analyzer

A beginner-to-intermediate Python cybersecurity project that analyzes log files and detects suspicious login activity.

## Features

- Read log files
- Extract IP addresses using Regular Expressions
- Count successful and failed login attempts
- Identify unique IP addresses
- Detect suspicious IP addresses with repeated failed login attempts
- Generate a text report automatically

## Technologies Used

- Python
- Regular Expressions (`re`)
- File Handling
- Lists, Sets and Dictionaries

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Run:

```bash
python main.py
```
